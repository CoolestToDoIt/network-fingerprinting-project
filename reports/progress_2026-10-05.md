## Milestones

I implemented leave-one-application-category-out evaluation and completed seven
experiments on the local Scenario B VPN dataset (15-second flow timeout,
18,758 flows). Each experiment trains on six categories and tests on the seventh.
The classifier is logistic regression with training-only median imputation and
standardization, using 23 native numeric time-based flow features.

| Evaluation | Accuracy | Macro-F1 |
| --- | ---: | ---: |
| Random baseline | 61.79% | 0.5996 |
| Hold out browsing | 52.86% | 0.4150 |
| Hold out chat | 51.44% | 0.4217 |
| Hold out email | 56.35% | 0.3604 |
| Hold out file transfer | 57.73% | 0.5325 |
| Hold out P2P | 44.61% | 0.3383 |
| Hold out streaming | 48.69% | 0.4867 |
| Hold out VoIP | 29.13% | 0.2256 |

Accuracy, macro-F1, macro-precision, macro-recall, class counts, predictions and
confusion matrices are saved in `data/processed/generalization/metrics.json`.
A compact comparison is retained in `reports/generalization_2026-10-05.csv`.
These initial results suggest substantial application generalization limitations
for this model. Test populations differ between folds and the random baseline;
these are descriptive comparisons rather than controlled paired estimates.
LOAO holds out categories, not individual applications or capture sessions.

## Open Problems

Session-disjoint evaluation is implemented and tested, but cannot yet be validated
on these real ARFF exports: they have no capture-session metadata. I removed the
fallback that invented one session per row. Recovering genuine flow-to-capture
provenance is necessary before reporting session-disjoint performance.

The feature pipeline previously created packet/byte features from incompatible
interarrival-time and rate fields. The new experiments use native features and
exclude target labels and numeric metadata; older results require rerunning.

Temporal generalization remains unmeasured. CIC-Darknet2020 is not an independent
modern capture: its official description says it combines ISCXVPN2016 and
ISCXTor2016. It should not be treated as 2020 traffic for a temporal experiment.
Source: https://www.unb.ca/cic/datasets/darknet2020.html
